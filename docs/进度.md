## 架构纪律落实

- 页面不直接碰 SQLite：全部经 `internal/data/sqlite` 的 `Store` 方法或 service。
- `internal/data/sqlite` 是唯一 import `plugins/sqlite` 的包。

  于是整个 `Referer: ...;User-Agent: ...` 被当成一个畸形 Referer，CDN 回 403。

  测试 `TestResolveFollowsShortLink`。
- 未登录时 DASH 只给到 480P/720P（更高档根本不在回答里），1080P+ 要填 `SESSDATA`；
  这是账号权限，不是解析失败。
- `biliBVID` 曾把 BVID 前五位转大写（`BV1Uv411N7Kh` → `BV1UV411N7Kh`）。
